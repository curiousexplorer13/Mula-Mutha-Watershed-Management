# Mula–Mutha Groundwater Preliminary Analysis

Study area: Mula–Mutha watershed, Maharashtra.
Analysis period: 2010–2025.
Source: National Water Data Portal / Maharashtra Ground Water Department.

Results:
- Wells inside watershed in full dataset: 44
- Wells with observations in 2010–2025: 34
- Wells used for trend analysis (>=10 annual observations): 31
- Significant declining trends (p < 0.05): 2
- Significant improving trends (p < 0.05): 5
- No significant trend: 24

Method:
Annual mean groundwater level was calculated per well. Sen's slope and Kendall's tau
were then used for preliminary trend detection. Positive slope means increasing depth
to groundwater (m bgl), interpreted as groundwater-level decline.

Limitation:
Bhuvan LULC request 28060 is awaiting approval, so groundwater-LULC causality is not claimed.
